Technical details

To show the setup code again on the appliance console, run sudo bittern setup-token --qr.

The setup code is in a root-only file on the appliance. The administrator password is stored as a salted PBKDF2-HMAC-SHA256 hash.

The certificate fingerprint is a SHA-256 hash of the certificate.
